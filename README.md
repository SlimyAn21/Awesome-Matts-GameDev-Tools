Id Tech Engine: Is the original game engine that Id Tech used to make doom. Created by John Carmack, with the help of John Romero, Dave Taylor, and Paul Radek. The game engine, while it looks 3d, is actually 2d or known by the community as 2.5d. Levels were created from a top down layout  that the player would raycast over to create a 3d look. Similar to Wolfenstein raycast technology was used for Doom and creating the 3d environments. One thing the engine perfected was dimensioning stairs and elevators. One thing that was great about the engine is support for mods thanks to John Carmack. That means mods can be made with the engine for doom. However one con was that you couldn’t test the level until it was completed and built, so minor issues in levels couldn’t be fixed as easily, which makes some secrets in level impossible to get.  

Pros: great tool that advanced the video game industry.
Cons: you couldn’t edit levels in game or test them out.

Blender: Blender is a free 3d modeling tool that is widely used by indie game devs and indie animators. The tool is free and can be downloaded on steam where it will receive updates or on blender.org. The tool has been praised for accessibility and advanced tools. The app is also open source and has a wide amount of community extensions. Game devs use it to make models and animation that can be imported into games. 

Pros: free and advanced
Cons: Particle effects are not main stream

Substance Painter is a great tool for painting 3d surfaces onto 3d models. Substance painter is an industry-standard tool which means a lot of companies use it. The tool also has a wide variety of community made materials that can be used to make multiple textures for 3d models. However the tool is not free, since it’s owned by adobe it’s a paid subscription. There is a one time purchase available on steam of $200 or $24.99 a month. It’s a great tool for creating 3d materials with a decent amount of pre-made materials.

Pro: Advance tool with pre-made assets that can be used.
Cons: Monthly subscription/adobe

Visual Studio: Visual Studio is a free code editor created by Microsoft. The software has an open library of coding languages that also has support for game engine work lodes. That software is great with unity because of its use of C#. The editor also will give suggestions to code and show errors before it’s compiled. The only problem is the Visual Studio is only on Windows devices and not Apple, it also uses a lot of memory too.

Pros: free and easy to use

Unity: Unity is a game engine that is used to make both 3d, and 2d games. Unity is free by default and only requires a subscription if your games make over a certain amount of money or you’re a big studio. The engine is by far the most popular with indie games for its user-friendly ui and accessibility. The main programming language  is C# and unity has great documentation when it comes to coding. Although a lot of people stopped using unity because of the install fee, unity was punishing out that never happened, but that’s not related to the tool itself. 

Pros: used by a lot of games so it’s easy to learn
Cons: the error logs are bad half the time.

Krita is a digital art software that is an alternative to photoshop when it comes to art. Krita has two methods of downloading, a free version on their website and a paid version on steam. The difference is that on steam you get updates while the first version you’ll have to redownload the app. The app is great for making concept art or art that could appear in your game somewhere like paintings. It comes with all the modern art features that most apps come with as well as an animation tool too. Krita is really a swiss army knife of art apps. The biggest difference from other apps is the amount of different brush styles krita offers for making art like a pencil tool and a paint brush tool as brushes. One con though is that krita's magic wand tool isn’t as good as photoshops. 

Pros: Great free art app that is used as an alternative to Photoshop
Cons: The magic wand tool isn’t the best.

Unity Asset store is a great tool for unity allowing you to buy and download tools made for the editor. People can make editor tools for unity and upload them to the unity asset store for free or costing money. Some assets in the store are free and some can become game changer to making games.

Ableton Live: Ableton Live is a program meant for making music, but it also doubles as a sound design program. Albeton presents many features for the user to use on their music and audio tracks, such as custom plugins, audio effects, instruments, drums, and more. Its user-friendly UI makes the integration process quick and easy for anyone transitioning from another software. Ableton also allows for live performance for vocals, the output of the audio goes through all of the filters that are on the track the audio gets recorded onto, allowing the user to hear what the output sounds like with the effects in real-time.

Pros: Ableton live performance features.
Cons: There is not much documentation on its live performance features.
